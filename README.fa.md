# حال‌خوب

آرشیو شخصی ویدیوهایی که دوست داری دوباره ببینی. لینک عمومی یوتیوب یا اینستاگرام
را ذخیره کن، برایش حس انتخاب کن و نسخهٔ ذخیره‌شده را در تایم‌لاین فارسی تماشا کن.

[English](README.md) · [نصب روی سرور](docs/server-deployment.md) · [مشارکت](CONTRIBUTING.md)

## قابلیت‌ها

- تایم‌لاین مناسب موبایل و لپ‌تاپ، پخش داخل همان پست و فیلتر براساس حس.
- جست‌وجو، علاقه‌مندی، یادداشت، ساخت و ویرایش برچسب‌ها.
- پخش خودکار ویدیوی داخل دید و کنترل صدا و توقف روی ویدیو.
- پخش صوتی پیوستهٔ ویدیوهای انتخاب‌شده؛ کنترل قبلی، بعدی و جابه‌جایی زمان.
- صف دانلود مستقل، جلوگیری از تکرار، نمایش پیشرفت و تلاش مجدد.
- ذخیره‌سازی محلی یا Cloudflare R2 Standard خصوصی؛ خروجی و بازیابی آرشیو.

## اجرای محلی

Python 3.12، FFmpeg و FFprobe و Node.js 22 نصب باشند:

```sh
git clone https://github.com/itsmohsenjalali/halekhoob.git
cd halekhoob
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-worker.txt
export DJANGO_DEBUG=1
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver 127.0.0.1:8000
```

در ترمینال دوم، از همان پوشه:

```sh
. .venv/bin/activate
export DJANGO_DEBUG=1
python manage.py runworker
```

نشانی محلی: http://127.0.0.1:8000. ثبت‌نام عمومی ندارد؛ فقط یک حساب شخصی بساز.
داده‌ها در پوشهٔ `data/` ایجاد می‌شوند و وارد Git نمی‌شوند. فایل `.env` خودکار
خوانده نمی‌شود؛ متغیرها باید در محیط فرایند تنظیم شوند.

## نصب روی سرور

[راهنمای Docker](docs/server-deployment.md) وب، PostgreSQL و پردازشگر را روی سرور
و فایل‌ها را در R2 خصوصی نگه می‌دارد. امکان پورت مستقل کنار سایت موجود فراهم است.
نمونه‌های تنظیمات فاقد کلید واقعی هستند و باید برای نصب خودت تکمیل شوند.

## محدودیت‌ها

ویدیوهای عمومی تک‌فایلی تا ارتفاع 720p و سقف فضای باقی‌ماندهٔ حساب پشتیبانی می‌شوند؛ محدودیت مدت، تعداد روزانه یا طول صف ندارند. مدیر در صفحهٔ `/admin` وضعیت سرور و کاربران را می‌بیند و سهمیهٔ فضای هر حساب را تغییر می‌دهد.
محتوای خصوصی، نیازمند ورود، لایو، پلی‌لیست و پست چندتایی پشتیبانی نمی‌شود.
گاهی منبع دانلود یک ویدیوی عمومی را از IP سرور مسدود می‌کند؛ در این حالت لینک
و برچسب‌ها برای تلاش مجدد باقی می‌مانند.

پخش ویدیو با تغییر تب متوقف می‌شود؛ حالت صوتی به پخش ادامه می‌دهد. پخش در صفحهٔ
قفل و رفتن خودکار به آهنگ بعدی به مرورگر و سیستم‌عامل وابسته است و روی همهٔ
گوشی‌ها تضمین نمی‌شود. بستن تب فهرست پخش را پایان می‌دهد.

برنامه تک‌کاربره است. لینک امضاشدهٔ R2 تا پایان اعتبار برای دارندهٔ لینک قابل
استفاده است. فقط محتوایی را دانلود کن که اجازهٔ نگهداری‌اش را داری. هزینهٔ سرور،
R2 و پشتیبان به میزان مصرف و تعرفهٔ ارائه‌دهنده بستگی دارد.
